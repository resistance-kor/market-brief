# [시황분석] 주식·코인 시황 대시보드

주식과 암호화폐 가격에 영향을 줄 수 있는 뉴스, 주요 지수 차트, 고점 대비 하락 종목을 한 화면에서 보는 페이지입니다.

## 화면 구성

- **시황**: 오늘의 시황 요약, 주요 지수 차트(코스피·나스닥·S&P500·비트코인·이더리움·솔라나·미국 10년물·금), 주식/코인/거시 뉴스, 다가오는 일정
- **고점 대비 하락 종목**: S&P500·나스닥100 중 52주 고점 대비 -30% 이상 하락 종목과 PER (의류·명품 계열 제외)
- **기타 종목**: 관심 종목 카드 (TSLL, 인튜이티브 머신스)

## 데이터와 갱신

| 항목 | 출처 | 갱신 |
|---|---|---|
| 비트코인·이더리움·솔라나·금(PAXG) | Coinbase Exchange | 페이지에서 **실시간** (WebSocket), 일별 종가는 data.json |
| S&P500·나스닥·미국 10년물 | FRED (최근일은 언론 마감 기사 종가로 보충) | 매일 07:19 · 22:19 KST |
| 코스피 | Trading Economics + 국내 언론 마감 기사 교차 확인 | 매일 |
| 뉴스·요약·일정 | 웹 검색 후 Claude가 요약 | 매일 07:19 · 22:19 KST |
| 고점 대비 하락 종목 | chartrow.com 종목별 페이지, stockanalysis.com 지수 구성 | 매일 07:19 KST |

- 모든 데이터는 `data.json` 한 파일에 들어 있고, 예약 작업이 이 파일을 갱신합니다.
- 금은 금 1온스 연동 토큰(PAXG) 가격으로, 현물 근사치입니다.
- 요약과 "영향 해석"은 수집 기사를 근거로 작성한 것이며 투자 권유가 아닙니다.

## 파일

- `index.html` — 화면 (Chart.js 사용)
- `data.json` — 시세·뉴스·종목 데이터
- `.nojekyll` — GitHub Pages가 파일을 그대로 서비스하도록 하는 설정
